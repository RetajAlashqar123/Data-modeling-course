# Data Modeling Course

This repository contains my labs and practical work for the Data Modeling course.

## Labs

### Lab 1 — Practical Review of Python Libraries
Review and practice of Python libraries commonly used in data modeling and data analysis.

### Lab 2 — Perceptron Algorithm for Binary Classification
Implementation of the Perceptron algorithm for a binary classification problem.

### Lab 3 — Feedforward Neural Network
Building a feedforward neural network using TensorFlow and Keras.

### Lab 4 — Training a Neural Network
Training and evaluating a neural network while analyzing its performance and behavior.

### Lab 5 — Model Selection, Hyperparameter Tuning & Regularization
Model selection using K-Fold Cross Validation, hyperparameter tuning, and Dropout regularization on the IMDB sentiment classification dataset.
